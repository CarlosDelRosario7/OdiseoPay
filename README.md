# OdiseoPay

Sistema **POS (Point of Sale)** desarrollado como proyecto universitario, con una arquitectura preparada para poder evolucionar en el futuro hacia un producto real.

## 🚀 Descripción

**OdiseoPay** es una solución de punto de venta orientada a la gestión de operaciones comerciales, permitiendo centralizar y facilitar procesos relacionados con ventas, productos, usuarios y otros elementos propios de un sistema POS.

El proyecto está siendo desarrollado como parte de un proyecto universitario por un equipo de estudiantes, con la intención de aplicar buenas prácticas de desarrollo, control de versiones y trabajo colaborativo.

## Procedimiento de revisión de código

Como mejora del proceso de desarrollo de ODISEOPAY, se establece una revisión formal de los Pull Requests antes de integrarlos a main.

1. El desarrollador crea una rama para sus cambios.
2. Abre un Pull Request y describe las modificaciones.
3. Adjunta las verificaciones o pruebas realizadas.
4. El revisor designado comprueba los cambios.
5. Si todo está correcto, registra su aprobación en GitHub.
6. El cambio se fusiona después de recibir la aprobación.

Responsable de seguimiento propuesto: Joel Barrientos Jiménez.

Cuando Joel sea el autor del cambio, otro integrante deberá revisarlo.
