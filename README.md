# OdiseoPay

Sistema **POS (Point of Sale)** desarrollado como proyecto universitario, con una arquitectura preparada para poder evolucionar en el futuro hacia un producto real.

## 🚀 Descripción

**OdiseoPay** es una solución de punto de venta orientada a la gestión de operaciones comerciales, permitiendo centralizar y facilitar procesos relacionados con ventas, productos, usuarios y otros elementos propios de un sistema POS.

El proyecto está siendo desarrollado como parte de un proyecto universitario por un equipo de estudiantes, con la intención de aplicar buenas prácticas de desarrollo, control de versiones y trabajo colaborativo.
